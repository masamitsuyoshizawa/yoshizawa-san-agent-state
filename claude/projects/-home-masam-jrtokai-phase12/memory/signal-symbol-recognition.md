**(a) 主たる信号 + 進行定位 [完了・四日市検証・コミット a...]**:
- 主たる = 基底グループ(1RA0/1RA1/1RA2/1RB0)で円が最右(下り)/最左(上り)。輪郭の太さ・×とは無関係。方向はCDiagramSignal.方向優先、不明多メンバー群は主信号_conf='要確認'。
- 進行定位 = 輪郭の太さ(輪郭暗率、暫定しきい0.44)。
- SignalLight に `主信号`/`進行定位`/`円pt_x` を加法SET。四日市場内1R=1R-A0が主信号+進行定位(x786最右、輪郭0.50)。API正答。

**(b) 懸垂/通常の装柱判別 [完了・四日市検証・コミット7c9a9ed]**:
- **群プロンプトvisionも一次幾何も失敗**。**信号1つを密クロップ(dpi700)+二択(矢じり=A懸垂型/逆T=B通常型)のvision**で確実に分離(`detect_haltype_vision`)。
- SignalLight.設置方法 に加法SET(通常型固定を実値化)。四日市場内1R=全懸垂型、蟹江上り3/1RA=通常、**蟹江13R=懸垂(以前手動是正が必要だった懸垂型を自動で正判定)**。
- 041(四日市場内1R=懸垂式・主たる1RA0)がAPI実質正答。

**(c) 補助信号(中継/遠方/誘導)の記号認識 [中継=完了・コミット637c2af]**:
- **利用者確定の命名規約(決定論)**: 補助信号機=元信号の記号**全体を丸括弧**で囲む。「(3L)」=3Lの中継、閉そくは「り」省略「(上1)」=上り1の中継。踏切図・連動図双方に記載(踏切図はキロあり)。
- 全体括弧の信号を 種別='中継信号機'・補助信号=true・親信号記号 に是正し `(補助)-[:AUXILIARY_OF]->(親)` でリンク。既存7件+西蔵(3L)@7537/(上1)@8815を追加。API正答。
- 記号: 中継=二重円+内円横線、遠方=円内に扇形状2線(7時半/10時半→中心)、誘導=破線円+斜線(連動表テキスト由来41RZ等既収録)。glossary/docsに集約。
- **残**: 全94踏切図の補助信号は元vision抽出で多くが脱落(現グラフ中継9件のみ、西蔵だけで2件=網羅されていない)。**踏切図の括弧信号を再vision抽出するバッチ**が残(踏切図はキロありで距離判断可)。遠方/中継の別は円内記号で判定。

**利用者確定の追加ルール(2026-08-03)**:
- **補助信号の原理**: 図に元信号が描かれていなくても、補助信号(例(2R))は必ず進行方向の先に元信号(2R)があり、その方向に駅がある。よって補助信号の所属駅=進行方向先の駅。踏切タイトルの下り側駅から推定可(小下/阿野田の(2R)/2R=亀山駅、下ノ割の(2R)=弥富駅)。同一の中継信号機が複数踏切図に描かれることがある(小下・阿野田の(2R)は同一、59k078m)。
- **補助信号のキロはx写像では不正確**(±200m。例(2R)を59015/59177と誤読、正=59078)。キロは利用者確定値or親信号キロ流用が確実。
- **入換信号機は円形でなく扇形(1/4円=12時-3時の90°、下に小円)**。円形でないので主信号(場内/出発/閉そく)でない。津街道第一の24R/44RZ/64Rは斜め軌道回路上で右70°傾いた入換信号機を閉そくと誤読したもの=非信号フラグで対象外化。
- **IKT等の軌道回路記号**: I=井田川i, K=亀山k, T=軌道回路。閉そくラベルへの軌道回路誤混入=非信号化。阿野田踏切の信号は閉そく上り1/下り1と中継(2R)のみ。
- **結果**: 実信号の所属駅不明=0(下ノ割/小下/阿野田(2R)・津街道第一/阿野田の誤混入を是正、9990/EC2反映)。

**残**: 補助信号キロの精緻化(現x写像近似・利用者確定分のみ正確)。遠方/中継の記号別の密クロップvision確定(現状Z接尾=誘導、括弧=中継)。[[crossing-diagram-symbol-rules]] [[crossing-tc-topology]] [[legend-extraction]]。

**特殊信号発光機の装柱方式(2026-08-03、T-1 p147権威)**: XC*=下り/YC*=上り。回転型=黒塗り上向き三角、点滅型=黒塗り縦長四角(円より小)。装柱=三角下の逆T→単独の信号柱、三角先端の半分黒塗り円→信号機専用でない柱(電化柱等)。抽出: batch_soutyu.py(踏切図XC/YCラベル右を密クロップvision4択)で70特発。068小下XC3-1=信号柱/069XC3-3=他所属柱、045貝塚XC3-1=単独柱/YC2-1=電化柱 正答化。※貝塚はラベルがベクタでtext不可のため図全体をvisionで判定(単独柱XC3-1/3-2/3-3・電化柱YC2-1、YC2-2不明)。ルールは docs/信号記号読取ルール_kansai.md + glossary(特殊信号発光機)。
