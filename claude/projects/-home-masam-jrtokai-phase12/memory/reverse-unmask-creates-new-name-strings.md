「戻す」荷(伏せ字 → 地名など)の後は、戻した後の本文と欄を、**既定の補完辞書の全部の語**で照らし、前には 0 回で後に現れた並びを数える。

**Why:** 2026-11-19、決351 の第 1 弾を手元の正本に反映した後、既定の辞書で照らすと、反映の前には 0 回だった名の語(語 A)が 13 か所現れていた。13 回とも、戻した地名などの端の字と、もともと在った隣の字にまたがる並びだった。第 1 弾の台の確かめ(W4・17 項目)は、荷の語だけを見ていて、これを拾えなかった。照らしに使った辞書が荷の語だけ(r1first-k6m1)だと、「伏せ残り 0」は作りから出る(同じ日に coord が、この 0 を利用者に報告して訂正した)。

**How to apply:** 戻す荷の台の確かめに「新しく現れた並びの数」を入れる(決351 追補 117 の 9 の (d)・第 2 弾の書き手の設計に入れる)。照らしの道具は、照らした辞書の名・sha16・語の数を必ず結果に出す。0 件を報告する前に、照らした語の集合が、問いたい集合の全部かを確かめる。関連 [[verify-zero-counts-before-reporting]] [[empty-set-is-subset-of-anything]] [[claim-wider-than-implementation]] [[r351-round1-apply-commit-gate]]
