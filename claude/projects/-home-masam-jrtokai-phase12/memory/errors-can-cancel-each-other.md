**2026-09-21・設備辞書の `parent` 是正で実際に起きた。**

**承認を得て `分岐器` の `parent` を `eq:軌道回路`(誤り)から正しい系統へ移したところ、別の質問の答えが悪くなった。**

| 「軌道回路」起点の `grouped` | 是正前 | 是正後 |
|---|---:|---:|
| 「分岐器」「転てつ」を含む語 | **26** | **1** |

**原因は、2 つの誤りが打ち消し合っていたこと。**

| 誤り | |
|---|---|
| **索引の誤り** | 表層「164号ポイント」が `eq:軌道回路` の別名(`confirmed`・共起由来) |
| **階層の誤り** | `分岐器` の `parent` が `eq:軌道回路` |

**誤った索引で軌道回路に寄っても、誤った階層のおかげで分岐器の子孫に偶然届いていた。** **階層の側だけを直したので、索引の側の誤りが露出した。**

**「是正が問題を作った」のではなく「是正が、隠れていた誤りを見えるようにした」。** **ただし利用者から見た挙動は変わる。**

**Why:** 誤りは独立に存在するとは限らない。ある誤りが別の誤りの影響を隠していると、片方を直した瞬間に、隠れていた側が表に出る。直した側だけを見て「効果」を測ると、悪化したように見えるか、逆に効果を過大に見積もる。

**How to apply:**
- **統制語彙やスキーマを直したら、直した箇所だけでなく、その値に依存していた経路も測る**(今回は「軌道回路を起点にした展開」で、是正の対象ではなかった)。
- **前後を比べる測定は、同じ版どうしで揃える。** 是正の前に測った数(fed の 17 件中 3 件など)と、是正の後に測った数を直接比べない。**他セッションにもそう伝える**(coord は共通表の改訂の項目に入れた)。
- **限定として一般論を書いて止めない。** 私は「`164号ポイント → 軌道回路` は誤った対応が `confirmed` になっている」を設計書に書いていたが、**それが検索でどう効くかは測っていなかった**。測っていれば、是正の前に気づけた。
