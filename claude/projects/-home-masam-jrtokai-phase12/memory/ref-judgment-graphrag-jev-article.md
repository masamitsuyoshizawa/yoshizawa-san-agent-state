要点: 埋め込み・ベクトル DB・グラフ DB を使わず、判断特化モデル Jev(TypeSafe AI・文章を生成せず「はい」の確からしさ 0〜1 を返す)に 6 か所の判断(登録 2・質問 4)を任せ、閾値で分岐。マスター(種別 9・関係 12・エンティティ 212)と文字列一致の事前絞り込み(69,960 問 → 1,457 問)でコストを抑え、探索は「もう答えられる?」が Yes になるまで隣接へ(最大 3 ホップ)。最終回答だけ Claude Haiku 4.5。35 問の比較で LLM 判断の 1/4 以下のコスト・ホップが要る問いで最良(参考値)。限界: マスターに無い物は辿れない・答えの無い問いは 2.8 倍のコスト・閾値調整が繊細・判断はブレる(決定的でない)。

本プロジェクトでの読み替え(2026-10-12 の所見): 判定は決定論の原則があるので、判断特化モデルは「構築時の候補提案(辞書の育成)」か「固定版のローカル cross-encoder(重み固定なら決定論)」として使うのが筋。探索ループは D-KB(質問の情報利得で次を選ぶ)と B の facets/doc を跨ぐエージェント層の形で試作可能。関連 [[federate-phase1-2-20260915]] [[dkb-recurrence-improvement]]。
