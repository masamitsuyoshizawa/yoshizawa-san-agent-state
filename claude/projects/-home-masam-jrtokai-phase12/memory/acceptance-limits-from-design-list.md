受入の合格を報告するときは、限定(照らしていないもの)の一覧を、自分が回した場面の記憶から書かない。受入設計の「回す一覧」(例 `docs/設計_中案_A_受入_dkb_20261028.md` §4 の 2・3 と §5 の K-1〜K-9)を 1 行ずつ、回した跡(道具・連絡)と突き合わせて作る。

**Why:** 2026-10-31 の W1 受入の最終 rep(20261031-0208)で「全部合格・限定つき」と書いた。しかし、同値性 (d)(K-3)・R2 の演習・戻しの手順書(K-6)・D4 の X 系(K-5)の 4 つが、限定の一覧から漏れていた。coord はその rep で合格と判定した(決334 追補 56)。次の依頼で材料を集めていて気づき、rep 20261031-0226 で訂正した。場面の道具を作りながら回すうちに、回していない項目が視野から外れていた。

**How to apply:** 合格・限定つきの rep を出す前に、設計の回す一覧の項目ごとに「回した・限定・未実施」を表にする。跡は grep で確かめる。未実施は限定と分けて書く。関連: [[claim-wider-than-implementation]] / [[report-from-the-consumer-side]] / [[next-phase-challenges-ab]]
