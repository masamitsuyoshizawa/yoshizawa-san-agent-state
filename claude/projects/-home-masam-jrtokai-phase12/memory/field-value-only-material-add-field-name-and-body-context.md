確認の画面の束で、資料の断片が「短い欄の値の全体」だけになる所(例: 欄そのものが 8〜16 字)には、**欄の名(一般の言葉)と、同じ事故の本文の中のその字の所を、参考として添える**。

**Why:** 決351 の残りの所の実の束(2026-11-19・回 1 の問 6 = 2 所 各 16 字・問 7 = 1 所 8 字)で、資料が欄の値だけになり、判じにくい見込みと coord が見立てた。断片は欄の値の全体なので、機械が切り出した短い字ではない(材料から数えて 20/20)が、前後の手がかりが無い。合成の見本では見つからない種類の事だった(合成の欄はどれも長かった)。今回は束を作り直さず、案内に「判じにくければ『分からない』で良い・その所は安全の側(伏せる案)」と書いて出した。

**How to apply:** 束の道具を次に作る・直す時に、layout の「短い単位」(40 字未満・改行なし・広げなし)が欄の値の全体である所を数え、そこに欄の名と本文の所を足す形を設計に入れる(dkb の材料に、同じ事故の本文の中の所を持ってもらう要がある)。合成の見本にも、短い欄の所を必ず入れる。関連: [[r351-residual-places-questions-bkb]]・[[human-review-rules-v3-adopted]]・[[review-screen-user-prefs-20261116]]
