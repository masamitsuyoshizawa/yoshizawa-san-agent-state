**順が「相手が先」なのに自分も計算を終えているとき、値を先に見せると相手の独立性が
消える。** 値は伏せ、計算済みファイルの sha256 先頭 16 桁だけを先に出す。

実例(2026-09-24・minus-d の件数): dkb が先に出す順だった。当方は規則が決まった
時点で計算できたので、数は書かず sha `2330d0c79ca1c0c4` を先に連絡文へ出した。
dkb の値が出た後に中身を開いて突き合わせ、5 つとも一致。後から数を合わせていない
ことが sha で確かめられた。rev も独立に出して 3 実装が一致した。

**Why:** 「独立に出した」は自己申告では担保にならない。先出しした hash が、
後から辻褄を合わせていないことの機械で確かめられる証拠になる。

**How to apply:** 計算は済ませてよい。出すのは hash だけ。ファイルは消えない置き場へ
(セッションの一時領域に置くと sha の約束ごと消える)。バイトを変えずに移し、
移動後の sha が同じことを確かめてから報告する。[[verify-filenames-before-citing]]
