照らしの 0 は「照らした語の範囲の 0」でしかない。伏せに使った辞書と同じ辞書で伏せ残りを照らせば、0 は作りから出る。

2026-11-19、P4 の前の数え(既存 700 件の配る版)で、bkb は「正本を伏せ直した版 r1first-k6m1 と同じ辞書で照らすのが筋」と推し、coord が採った。結果は伏せ残り 0 で、そのまま報告した(rep 0117)。coord に 0 の読みを問われて辞書の語の数を見たら、r1first-k6m1 は第 1 弾の語だけの辞書だった(甲 11・乙 1。本体の既定は甲 387・乙 24)。本体の既定の辞書で照らすと、推定 826 か所・149 文書。rep 0126 で訂正した。

**Why:** 版の名(sha16)と「正本を伏せ直した版」という役だけを見て、中身の大きさを確かめずに、全部の語を持つ辞書だと思い込んだ。照らしの道具も、照らした語の数を出していなかった。
**How to apply:** 辞書・一覧・規則の表で何かを照らす数えでは、回す前に表の大きさ(類ごとの語の数)を見て、結果にも書く。「作った物と同じ物で照らす」組は、0 が作りから出ないかを先に問う。0 を報告する時は、照らした範囲を同じ行に書く。関連: [[recommendation-must-fit-own-premises]]・[[assumed-current-state-without-checking]]・[[verify-zero-counts-before-reporting]]・[[dist-pdf-unification-r352-57]]

追記(同じ夜・01:51): 続けて 44 か所の内訳で、辞書と材料だけを照らした結果から「決351 のどちらの弾の範囲にも無い」「辞書を切った後で足された語の見込み」と書いた。dkb の独立の確かめ(rep 0144)で、2 語とも決351 の判断の一覧(2 回目の一覧の「迷う」・追補 46 の「伏せない」)に在ったと分かった(rep 0151 で訂正)。**「どこにも無い」と書く前に、判断の記録(dec の追補・一覧)まで経路をたどる。** 照らした物を同じ文に並べる。関連: [[absence-claim-read-whole-path]]・[[claim-wider-than-implementation]]
