閾値や規則を「既知の正解を全部残す」で評価する前に、**その既知の集合がどの物差しで見つけられたか**を確かめる。

2026-11-07、双子の規則で「要約の 3 字の重なり ≥ 0.3 で既知の 98/98 を残す」と書いて rev へ出した。rev は偏りを指摘した(私も一言「偏りがある」と書いていたが、調べていなかった)。実測すると 96/98 組が要旨先頭 40 字の一致を満たし、当時の検出規則の 1 つがそれだった。同じ物差しで選んだ集合に同じ物差しを当てていたので、ほぼ循環だった。

**Why:** 「偏りがあるかもしれない」と注記するだけで済ませると、数字が根拠として独り歩きする。調べれば数分で分かることだった。
**How to apply:** 既知の正解を基準にするときは、検出の方法を文書と辺の属性で読み、評価に使う物差しとの重なりを数える。循環なら、物差しに頼らない条件(今回は同じ日 + 同じ場所)へ替え、未知の側を測る手順を別に持つ。関連: [[collation-derive-expected-from-source]] [[criterion-not-tool-output]] [[bulk-intake-r352-dkb]]
