合格した道具の共通の部品(子の過程の起動と待ち・外の命令の待ち・期限の計算)を直す時は、合格した版にあった守りを 1 つずつ並べ、合格した版と新しい版に同じ代役(時計・子の起動の遅れ・外の命令の遅れ)を当てて、「合格した版が拒む場合は新しい版も拒む」を試験で照らす。

**Why:** 2026-11-22 に決351 の当日の道具(dkb-day)で、期限の札をそろえる直し(改訂 8)の時に `child` の上限を「起こす前に決める」形にした。その時、合格した版 298704728 にあった「起こした後の待ちの直前に残りを取り直す」を落とした。rev が両方の版に同じ代役(残り 1 秒・起動 1.5 秒・結果 0)を当てて見つけた。結果は、合格した版が CHILD_TIMEOUT、新しい版が期限を 0.5 秒越えて 0 だった(rev rep 20261122-1731)。coord から「rev がした事を試験に」と頼まれた。新しい試験は、直した所の正しさしか見ておらず、元の守りが消えた事は見えなかった。

**How to apply:** 共通の部品の差分を出したら、合格した版の同じ関数を読み、守り(照らしの位置・順・札)を並べて比べる。試験は、合格した版を `git show` で取り出して別の名で読み込み、同じ代役で両方を走らせる形にする。取り出せない時は試験を落とす(黙って飛ばさない)。関連: [[mutation-harness-needs-control]] / [[isolate-the-change-before-blaming-version]]
