専門家に渡す確認項目は、問いに加えて「答えで何が変わるか」を書く。さらに、**返ってきうる答えを並べ、どの答えでも実装が一意に決まるか**を確かめる。

例:
- 「両方」(OR か AND か)
- 「条件によって変わる」
- 「一部だけ重なる」
- 「推奨・参考」

こうした答えは、問いの時点で分けて聞く。分岐が決まるまでは厳しい側で止める、とも書いておく。

**件数(2026-09-17 時点)**: T0 の 17 項目のうち**分岐があるのは 14**(#1〜#6・#8・#10〜#13・#15〜#17)。**分岐が無いのは #7・#9・#14 の 3 件。** 一時期「13 項目」と流通したが、完了報告 §9-1 で fed が訂正した。**古い 13 を引かない。**

**分岐が無い項目でも、問いを置き換えない**(rev 己4 の R2・2026-09-17)。「選択肢を作らない」ことと「問いを読みやすさの確認にまとめる」ことは別である。#7 は**権限者の特定**、#9 は**候補原因の対応範囲の確定**で、#14 の「誤解しないか」とは違う問いだった。自由回答にするなら、**項目ごとに何を答えてほしいかを書く**(役職・権限区分と適用条件 / 対象候補と含める・除外する範囲と理由 / 文言ごとの修正案と理由)。**未回答・判断不能・回答同士の矛盾は「未確認」として保持し、既定値で埋めない。**

**「停止位置に効かない」を、専門の判断が要らない根拠にしない。** コードの静的確認で言えるのは「現行の契約と未承認の状態を保つかぎり停止位置を動かさない」ことだけで、無審査で採ってよいとも、文言に危険な誤解が無いとも言えない。

**問いだけでなく、答えるのに要る資料を添える**(R1)。転記元に定義が無いものは特に落ちる — 安全区分 A0〜A4 の定義(読み方表 §10.1 にあり、準備資料 §2 には無い)、同名候補の識別に要る情報(ID でなく親の型式)、出典の版と位置、対象文言の全量。**「長く書くと読まれない」は導入の話で、別添を削る理由にしない。**

**Why:** T0 の準備資料 §2 で「答えで何が変わるか」の欄を足した時点で十分に見えていた。ところが coord の一言で見直すと 14 項目で答えの側が分岐した。曖昧に読める答えを受け取っても実装は決まらず、聞き直すころには元の文脈が失われている。

**How to apply:** 答えごとに次の 3 点を書く。
- 直すもの(overlay・契約・表示)
- 止まる位置を下げないこと
- snapshot を取り直す場合は、coord の個人情報の再点検を経ること

さらに、**回答の後に残るものを 3 つに分けて数える**: 専門家が選ぶ分岐 / 表し方を選ぶ場面 / 当方に残る設計判断。混ぜると「残るのは 1 件」のような過少記載になる。
