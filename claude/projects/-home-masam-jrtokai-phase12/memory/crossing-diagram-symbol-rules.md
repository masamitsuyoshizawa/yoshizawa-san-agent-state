踏切制御図表(関西本線)の図記号を決定論解釈するための規約(利用者提供 2026-07-31、上野踏切=74_上野踏切.pdf を例に確認)。[[crossing-diagram-jiso-extraction]] の抽出精度向上の根拠。

- **図タイトル=路線・駅**: 例「関西線 河曲駅加佐登駅間 上野踏切保安装置制御図表(電子)」。駅間の場合は **前=上り側の駅、後=下り側の駅**(上野例: 河曲駅=上り側、加佐登駅=下り側)。駅に隣接する踏切はその駅名。
- **図の左右=方向**: 図は必ず **左=上り側、右=下り側**。
- **信号機の向き(回転)=方向【方向決定の唯一の正解】**: 信号機記号=円形+下に上下反転した「T」(通常型)。**円がTの右側(右90°回転)=下り用**、**円がTの左側(左90°回転)=上り用**。
  - **懸垂型(OH形)の例外(2026-07-31)**: 一部の信号は懸垂型設置で、円の「上」に上向き矢印が付く(逆さTでない)。懸垂型は回転の意味が通常と逆で、**矢印が右=下り、左=上り**。例: 春田駅13R(蟹江図)は懸垂型・矢印右=下り出発。→ 通常型/懸垂型を判別しないと同じ「マスト右」でも方向が逆になる。**通常型/懸垂型の自動判別は幾何(矢じり vs 逆さT)もvision(記号形状読取)も信頼できず失敗**(密な図・斜め中空の矢じり)。よって実装は通常型仮定(detect_rotationはマスト側のみ返し direction_from(mast_side,'通常型'))、懸垂型は稀なので個別手動是正(13R実施済)。懸垂型の網羅的自動化は将来課題。
  - **重要(2026-07-31 利用者強い指摘)**: **記号のL/Rで方向を決めてはならない**。L/Rは駅の操作盤のてこ向き(操作盤が線路のどちら側か)で決まり、R=上りになる踏切も多い。方向は必ず信号記号の回転向き(幾何)で判定する。蟹江ではたまたまR=下り/L=上りだったが、下ノ割では逆(1L/12L/13L=下り、2R/3R/11R=上り)。私が当初入れた記号L/R規則(dir_of_sym / FU1 / Phase3の記号由来回転)は**誤りで撤廃**。`crossing_jiso_geom.detect_rotation`(マスト=T側を画素判定。マスト左=下り/マスト右=上り)が唯一の権威。下ノ割で方向・種別ともGT一致を実証。
- **閉そく信号機 vs 場内/出発の判別**: 信号機の**円形の中に小さな円形(信号標識)があれば閉そく信号機**。無ければ**どこかの駅の場内または出発信号機**。→ 上野の 1R/11L は小円が無いので閉そくではなく場内/出発(現グラフは誤って BlockSignal 化 = 要修正)。
- **場内 vs 出発**: 出発信号機は**駅の近くかつ駅からの進行方向側**に置く。進行方向の逆側に駅が無ければ、その信号は**進行方向の先にある駅の場内信号機**。例: 1R(下り)の上り側(左)に駅が無く、下り先に加佐登駅があるので、1R=**加佐登駅の下り場内信号機**。11L(上り)=**河曲駅の上り場内信号機**。
- **特殊信号発光機の向き**: **XC系=下り、YC系=上り**。記号=黒塗り三角形+下に逆「T」。**右90°傾=下り列車用、左90°傾=上り用**。※XC3-2 は記号が異なる(意味は利用者から追って連絡)。信号機・補助信号機・特発は**必ず左右どちらかに90°回転**している。
- **軌道回路の境界=信号機**: 軌道回路どうしの境界には**原則として信号機(閉そく/場内/出発のいずれか)がある**。ただし駅付近で軌道回路中に転てつ器がある場合、境界は単純な上り/下り2点でなく**転てつ器で枝分かれした先にそれぞれ境界があり複数**になり得、その全境界に信号機があるとは限らない。将来の軌道回路トポロジーの正しいグラフ化のため継続検討(利用者依頼)。

**信号記号ルールの集約(2026-08-03)**: 図読取+回答生成の参照点として `docs/信号記号読取ルール_kansai.md` に一元化(+回答用に glossary へ)。利用者が精密化した確定ルール:
- **主たる信号 = 進路別グループ(1RA0/1RA1/1RA2/1RB0)で円が最も高い位置=下り一番右/上り一番左**。輪郭の太さ(=進行定位)や×とは無関係。純粋に円のx位置。四日市場内1R実測で1RA0=x786最右=主たる を確認。
- **懸垂/側壁 = マスト先端が矢印(進路方向に回転: 下り=円の右に右向き矢印/上り=左向き)**。通常=逆T(⊥)。四日市1Rは各円に矢印先端(高倍率で確認)=懸垂。**visionは通常/懸垂を誤判定(全通常と誤答)、幾何は円・バー・ラベル近接で要作り込み**。矢印先端の三角(spread根元→点へnarrow)が特徴。
- **× = 注意線(╲)+進行線(╱)の両方**が描かれた現示状態。主たると無関係。
- **進行定位 = 輪郭の太さ**(太○)。四日市1RA0=輪郭暗率0.50(他0.31)。
- **補助信号記号**: 遠方=円内▷/中継=円内横棒/誘導=破線円(R-2凡例)。連動図の誘導信号機はテキスト由来で収録済(41RZ等)。
