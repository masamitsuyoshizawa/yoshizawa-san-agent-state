2026-09-28(決126): federate の c_nl の測定を「1 回 0.02〜0.03 USD・計 1.2」と見積もったが、実測は 1 問 0.18 USD(NL→Cypher と答えの整形で Opus 5 を 2 回・schema の要約込みで入力の中央 17,578 トークン)。台帳の上限(3.5)の手前で 17 問目に止まった(rc 3・設計どおり)。

**Why:** 経路の入力は「問い + 少しの指示」と思い込みやすいが、実物は schema や根拠のブロックで桁が違う。2 回目の呼び出し(整形)も見落としやすい。上限の手前で止まる仕組みがあったので実害は無かったが、測定が途中で終わる。

**How to apply:** 見積りの前に、(1) その経路で 1 問あたり LLM を何回呼ぶかをコードで数える、(2) 1 問だけ回して入力の実トークン(または UTF-8 のバイト)を見る、のどちらかを済ませる。1 問の試し回しは費用がほぼ無い。見積りを出すときは「実測の 1 問から」か「置いた仮定から」かを書き分ける。関連 [[estimates-not-labeled-as-measurements]] [[opus55-production-switch-item]]
