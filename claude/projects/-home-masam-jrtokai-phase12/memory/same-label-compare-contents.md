2 つの文書が同じ札(「投3」「S2」「別検査」など)を使っているとき、「同じ札に置いた」で一致とせず、表を 1 行ずつ並べて中身を突き合わせる。

**Why:** 2026-09-24、fed は 投1/投2/投3 を「比べる投影の 3 つ」、bkb は同じ札を「投1 比較 / 投2 別検査 / 投3 対象外」という別の区分に使っていた。両者が「llm_calls を投3 に置いた」と書き、一見一致していたが、fed = 不変値として比べる・bkb = 対象外で、bkb の側は rev の指摘(値を変えても検出できない)をそのまま残す誤りだった。札が衝突していなければ見つからなかった(bkb rep 20260924-0255)。

**How to apply:** 定義を「1 つに揃える」指示を出すときは、揃える先(誰の定義が正本か)を名指しし、受ける側には札でなく中身の表で突き合わせて差分を報告させる。関連: [[claim-wider-than-implementation]]・[[verify-filenames-before-citing]]
