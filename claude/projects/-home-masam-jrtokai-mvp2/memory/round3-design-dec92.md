第 3 回で dgr が作る物(計画は 11/13 14:35 承認・決95・決100 で足した決まりを含む)。[[drawing-redesign-phase0]]

1. S1 の束線の候補: 横切る配線で割れた面を 1 つにまとめる(短い片も幅がそろい端が近く並ぶならまとめて長さを見る・決100 §1.1 の 2)。
2. rg3 の束線: 構造の範囲を切る時、範囲の外へ両側に出る長い直線(hl / vl の塊)は横切る配線として切らない(決100 §1.1 の 1・利用者の答え「反対側へまっすぐ続く」)。両側に配線があるがずれている所・片側に曲がりがある所は、つながず確認に回す(§1.1 の 3)。
3. 束線の入り口の結び: 端の種類 bundle の網ごとに配線番号を結ぶ。同じ束線の同じ番号をつなぐ(答え 3)。番号なし・相手なし・読みの確かさが低い(3/3 でも S3 の確定でもない・決95 §3 の 1)・決まらない は unresolved。出力は read の bundles[{id, poly, entries, links, unresolved}]・網は分けたまま(まとめ方は確定の道具で 3 者が決める)。
4. 付記(S2 の分けが「配線の付記」): 記号として網を切らず、枠の中の墨を除いて、向かい合う辺に入る端を軸のそろう物どうしで 1 本ずつつなぎ直す。組にならない線(シールドからの接地など)はシールドの網(答え 2)。矢印は向きを墨の重さで持つ。出力は wire_marks。
5. 接続点(大きな黒丸): 切らない(第 2 回で済み)・出力に大きさ。
6. カム展開図: 枠に着く端(cam)を、枠の中の横の線の行に結ぶ。閉じる範囲は読まない。出力は cam_charts。
7. 配線番号の点検: 1 つの網に違う番号が混ざる・同じ番号なのにつながらない(束線・読み替え・他図参照で結んだ物を除く)。S5 の先頭の束に出す。
8. hub の HOLD から s5 を外し、S5 を開く。合成の図 M4 の正解(structures・wire_marks・bundle_links・bundle_unresolved)で試す。
