利用者は、文書の社名を、押印だけでなく本文も伏せると決めた(決140・2026-11-17)。範囲は取引先とメーカー・顧客自身と関係の会社(公の機関は伏せない・決146)。

- **止め(決142)**: 正本の字を AI に読ませる新しい回(エージェントの正本の回・QA の評価)は、伏せが済むまで始めない。解く条件は 3 つ: (a) 計画の承認 = 済み (b) 候補の確かめ = 済み(2026-11-18・35 語のうち社名 9) (c) 当たる本の入れ替えと伏せ残し 0 の数え。そろったら coord が利用者に諮り、dec で解く。
- **作り**: 伏せの関数は `scripts/dcr/company_mask_core.py` の 1 つ。社名の表は git 外の `data/private/company_mask/table.json`(第 1 版・sha16 14ca04814c83ec5b)。AI には記号(〔社A〕の形)だけが渡る。答えは `scripts/agent/names_view.py` が、ファイルに書かずメモリの上で戻して画面に出す(決147)。プロンプトは第 2 版(記号をそのまま写す 1 文・sha16 e89c8a713a0cf650)。
- **入れ替え(決149)**: 7 本(作業標準 2・規程と基準 4・前の説明書 1)。演習の終わりのダイジェストの見込みは eb2cdbaa0d1b409c。前の説明書には、OCR の誤読 1 語の人の直し(決148)も乗る。
- coord の手番: 表の版が上がるたびに、漏れの検査の私的な一覧(`data/private/leak_terms.txt` の [D])に社名を足す(語は画面に出さない)。
- 限り: 伏せ残し 0 と言えるのは、表に在る名だけ。略した名・画像の中の社名は外。顧客に取引先の名の表を頼んでいる。前に AI に送った事例報告の抜き書きの記録 8 ファイルは、私的な置き場へ移す(決150)。
