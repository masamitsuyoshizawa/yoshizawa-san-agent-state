2026-11-22 からの dgr の rep(cc acc)と、coord の既読の注記と、coord の利用者への報告に、図面 2a8c の、新しい欄の読みの数(行を採った機器の数・部分ごとの記号の数・名称表に結ぶ問いの状態ごとの数・番号の組の数)が書かれている(決212 §3・coord の見落とし)。物差しの第 20 版で、acc は、これらの欄を照らす期待を新しく作る。

**Why:** 受入の独立。「凍結済み」は、期待の版と、その版が照らす欄の単位(決195 §5)。2a8c は第 1 版で凍結済みだが、新しい欄の期待は、まだ無い。

**How to apply:**
- 新しい欄の期待の凍結の info を出すまで、次を画面に出さない: `docs/comms/2026112[2-9]*_dgr_to_*` と、それより後の dgr の便の、summary・status・本文。`docs/comms/INDEX.md`(summary が入る)。
- 取り込みは、出力を捨てて行う(`git merge main >/dev/null 2>&1; echo $?`)。取り込んだ便を読む手順では、dgr の便を、名ごと外す(`grep -v '_dgr_to_'`)。coord・kgb・dcr の便は、読んでよい(coord に、acc 宛ての dec と info に、これらの数を書かないよう頼んだ)。
- dgr の便への既読の注記は、「読んでいない(第 20 版の新しい欄の期待の凍結まで・決212)」。
- 2026-11-24 に、機械で照らした: 2026-11-22〜24 の dgr の便 34 本の、summary・status・本文 803 行は、acc の会話の記録の道具の出力に、1 行も出ていない。
- acc が見た物(数): 名称表の読みの確かめの問いの数(決188・決190 と、2026-11-21 の dgr の rep の summary)・問い K の時間の見込み(決193・決196)・見本の段の答えの数と種類(決205 §4)・大きい黒丸の問いの数(便の名)・2026-11-21 の 2a8c の網と端子の数(dgr rep 2306 の summary)。新しい欄の 4 種の数は、見ていない。
- 期待の作り方(案・acc の画面で諮る): 利用者の答え(原本の図を見て、acc の記入票で)と、acc の独立の読み(凍結済みの期待の第 1 版の位置と名を、問う所を選ぶ手掛かりにだけ使う)。dgr の確定の出力は、材料にしない。利用者が、まとめの数を見ている事は、不確かの欄に記す。
- 2a8c の確認の後の出力は、1-6 の知らせまで読まない(P11・変わらない)。
