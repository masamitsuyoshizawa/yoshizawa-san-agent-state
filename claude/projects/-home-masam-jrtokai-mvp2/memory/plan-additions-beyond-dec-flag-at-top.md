決115 の後に作った作りの計画に、決115 に無い直し(最初の見出しより上の字の行を要素にする)を入れ、利用者は Plan Mode で承認した。dcr は info 2102 の §1 に「決115 の計画にあった」とだけ書いた。coord は取り込みで気付き、承認の時刻と計画の箇所を rep 2103 で求め、決117 として追補を記録した。

**Why:** dec が正本である。dec に無い直しは、承認があっても dec に載らず、正本の入れ替えの範囲(どの本を含めるか)の判断が止まる。
**How to apply:** 作りの計画が先の dec より広い時は、計画の段で「決 N に無い直し」と印を付ける。info か rep の summary の頭に、その直し・承認の時刻・計画の箇所を書き、needs_user_approval: yes で追補の記録を頼む。[[read-whole-section-before-dec]] と同じく、dec と計画の差を自分で照らす。
