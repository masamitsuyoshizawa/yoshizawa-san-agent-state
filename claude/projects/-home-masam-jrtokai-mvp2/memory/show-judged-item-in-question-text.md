8732 の誤読の確かめで、「印の付いた語は正しく読めていますか」と問い、機械の読みの字は右の画像の下の小さな欄にだけ置いた。選び「読取のとおり」に中身が無かった。利用者は、機械の読みが表示されていないと指摘し、回を止めた。裏の画面で測ると、字は作りの中に在り最初の画面にも見えていた(15/15)が、左の問いと選びには 0/15 だった。印・図の枠・欄の数えも、agy の点検(見本も同じ作り)も、これを拾えなかった。

**Why:** 人は問いの文と選びを読んで答える。正誤を問う物が問いの側に字で無いと、「何の正誤か」が分からない(R17 の再発・R22)。数えが「印と欄が見える」だけでは、問う物そのものの在り処を照らさない。

**How to apply:** 機械の読みや案の正誤を問う問いは、問いの文に「機械は〜と読みました」と書き、「同じ」の選びにも、その字を出す。配る前の数えに、問う物の字が左の問いの側に在り最初の画面に見える数を足す(misread_check.py の reading_shown の形)。[[synthetic-sample-misses-real-length-layout]] [[review-screen-design-principles]]
