確かめの画面を利用者に案内する前に、coord は、次の確かめの数が配りの知らせに在る事を見る。無ければ案内しない。

1. 問いが正誤を問う物が、画面に字か印として出ている(決176)。
2. 印の線と塗りが、問う字や線に重なっていない(決180・実の回で 0)。
3. 選びの全部(「分からない」を必ず含む)で、答えと備考が保存され、開き直して読み戻せる(決183・実の回の写しで)。
4. 切り抜きや拡大の絵に、問う物が入っている(決183・字の層の枠だけに頼らない物差しで)。
5. 切り抜きに、**判断の手がかり**(問う記号の近くの番号の字・相手の記号)も入っている。問う物が入っていても、手がかりが外なら答えられない(2026-11-22・8755 の名称表の問いで「分からない」13/58・備考 2 つがこの訳)。

**Why:** 2026-11-21 の 1 日で、利用者が 4 つの不備を続けて見つけた(8736 の枠が字を隠す・8754 と 8732 も同じ・作り直した 8732 で「分からない」の備考が消える・切り抜きに対象の字が無い)。どれも、作り手の数え(印が出ている・切り抜きが出ている・大きさ)は通っていて、coord も同じ数えを回して「配ってよい」と伝えていた。出ている事と、働いている事は別だった。紙を写した本は、字の層の枠が刷られた字とずれる。

**How to apply:** 作り手の数えを回し直すだけにしない。数えが「何を保証していないか」を 1 つずつ問う(見える → 読める → 答えられる → 保存される)。新しい種類の画面や、作り直した回は、coord が写しの回で 1 問を通しで答え、記録の行を数で見てから案内する。docs/08 第 6 版の候補。関連: [[review-screen-design-principles]]・[[show-judged-item-in-question-text]]・[[synthetic-sample-misses-real-length-layout]]。
