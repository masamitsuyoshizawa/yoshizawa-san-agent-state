ブランチを取り込んだ時は、知らせのメッセージが挙げた連絡文だけでなく、その取り込みで入った連絡文の全部を並べて、1 本ずつ読み、既読の注記を付ける。

**Why:** 2026-11-18、dgr の rep 0046(rep 0041 の訂正・規格の項は細目の下の段で絞れる・候補は最大 20 項)が、部品 0.8.2 の取り込みに一緒に入っていたのに、coord は読まず、注記も付けなかった。古い数(候補は最大 67 項)で利用者に「中間の形は作らない」を勧め、利用者がそう決めた(決150)。後で気付き、利用者に伝えて決め直してもらった(決152)。

**How to apply:** 取り込みの後に `git diff --name-only ORIG_HEAD HEAD`(競合の時は `git status --short` の A の行)で、入った docs/comms のファイルを並べる。読んだ本に「coord: 既読」を付ける。区切りで、coord 宛ての rep と info のうち、coord の注記の無い物を数える(0 であること)。関連: [[read-whole-section-before-dec]]
