凍結の前の図(例 b08e)の値を画面や連絡文に出さないことと、その図について確かめないことは別。値を出さない形の真偽(空 / 空でない・合否・良 / 否)は、スクリプトで真偽だけを出して自分で確かめてから書く。

**Why:** 2026-11-02、dgr が rep 0006 で kgb_input の `eid_map` を「3 枚とも空」と書いた。f12fc と 2a8c だけを確かめ、b08e は値を出さない流れで確かめずに推して書いた。b08e は空でなく(重なりの枝番 ~k のずれの旧 → 新)、coord が決38 で食い違いを見つけ、info 0011 で訂正した。未確認を確定として書いた誤り。

**How to apply:** 「3 枚とも」「すべて」と書く前に、各図について真偽を出す確かめを回したかを見直す。凍結の前の図は、件数や中身を出さず `bool(...)` や合否だけを出すスクリプトで確かめる。関連 [[acceptance-independence-no-element-kinds]]・[[acc-a-layer-values-before-freeze]]。
