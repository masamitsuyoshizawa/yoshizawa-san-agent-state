`~/.config/dynfw-backup/deny_terms.txt`(決2 の禁止語の一覧)を、cat などで開いて表示しない。漏洩の点検に使うときは、`grep -c -i -F -f <一覧> <対象>` のように、一致の件数だけを返す形にする。一致した行の中身を表示しない。

**Why:** 決17(2026-10-21)で「AI のセッションは平文の封印辞書と原文の索引を読まない」と決めた。この一覧も封印辞書と同じ扱いにすることは、決18(2026-10-22)で確定した(docs/05 v1 §4)。決18 の時点から、語を誰が足したかによらず、AI のセッションは一覧を開かない。coord は第 1 巡まで、一覧を開いて照合に使っていた。

**How to apply:** 漏洩の機械点検のたびに、件数だけを返す照合を使う。当たりが出たら、その箇所の確かめ方を利用者と決める。一覧を自分で書き換えない。確定と追加は利用者が行う。

当たった語を探すときは、`grep -n ... | cut -d: -f1` で行番号だけを見て、候補の語を 1 語ずつ一時のファイルに書き、件数で確かめる。2026-11-06 に、姉妹プロジェクトのリポジトリ名(ローマ字の略)が当たると分かった。古い文書やファイル名にはその名が残っているが、新しい記録では「姉妹プロジェクト P1」と書く(決129)。
