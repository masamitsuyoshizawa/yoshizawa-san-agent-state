試作 α の契約の試し(checks/contract_tests_*.py)と変異の実行器(checks/mutants_*.py・tools/mutants.py)は、同じ作業ツリーで別の過程と並行して回さない。全体の実行器(checks/run_stage3_fix.py)を背景で回している間も、ほかの試しを回さない。

**Why:** 2026-10-27(req 1723)、対象を持つ 8 つの実行器を背景で回している間に、別の過程で雛形の写しと静的な対照を回した。3 件が不成立(対照の不合格 2・写しの出力が全て null 1)になり、単独で回し直すと 3 件とも宣言した理由で検出した。読込の時の副作用は見つからず、原因は特定していない(推定: tmp の置き場か台帳の取り合い・壁時計の戻り)。

**How to apply:** 試しは 1 本の過程で順に回す。背景で回すときは、終わりの知らせまで作業ツリーで python の試しを起こさず、文書の作成だけをする。不成立が出たら、まず単独で回し直して再現するかを見る。[[mutant-check-compare-reasons]] [[wsl2-monotonic-clock-fast]]

**追記(2026-10-27 req 2122):** 全体の実行器を回している間は、proto/ の下のファイル(コード・規範)も書き換えない。pilot・開発・回帰の模擬の通しは prepare で凍結の候補(tools/freeze_stage2.py の群の sha256)を作り、門でいまのファイルと照らすので、途中の書き換えで対照が「凍結の候補の不一致」で落ちる。待つ間は docs/ の記録とメモリだけを書く。

**追記(2026-10-28 req 0015):** 全体の実行器を単独で回しても、FXME-CROSS の中で回る既存の対照 FXCB-LOW-AGENT-OTHER-CALL が 1 回だけ落ちた(単独・組み合わせ・直前の区間の順で再現せず、2 回目は rc=0)。秒の壁時計から起動と模擬の記録の時刻を取る対照で、壁時計の戻りが原因の候補(未確認)。1 回の rc=5 で直しを疑う前に、この形の一時の失敗を疑って回し直す。
