## 3. 計画

### 3.1 型ごとの代表を問う(docs/08 の代表の問い・同じ判断を繰り返させない)

- 問う字: 答えで分かっている 2 型を除く 21 型の、型ごとに代表 1 つ(型の中で、上と下の記号の間が最も狭い字・同じなら上の物)。
- 問いの形: 1 問に図 1 つ(記号のまわりを寄せた図・部品の決まり)。
  - 問う字に青い短い線、上の記号に灰色の破線の短い線、下の記号に緑の短い線(どれも字と記号を避ける)。
  - 問い = 「青い短い線の先の字は、どの記号の名ですか」。
  - 選び = 上の記号(灰色)の名・下の記号(緑)の名・どちらの名でもない(はたらきの名など・備考)・分からない。
  - 機械の読み = 今の結び先(上か下か)。

### 3.2 答えを当てる(決定論)

- 型の答えを、その型の字の全部に当てる(1 つだけの型は、その字だけ)。答えで分かっている 2 型は、段 2 の備考どおりに当てる(下の記号の名)。
- 「どちらの名でもない」の型は、どの記号にも結ばない(項目 3 = はたらきの名の字の材料にする)。
- 当て方は、組み直し(`p1_s4_rebuild.py`)の読みの重ね(Overlay の post・結びの直し)として足す。確かめた結びは git 外の新しい確定(段 S3 の置き場の下・結びの確定)に置く。`p1_merge.py` の決まりそのものは変えない(f12fc・b08e の確定の出力を動かさない)。
- プロファイルとプロンプトは変えない。

### 3.3 問い K の組への響き

- 結びを直した組み直し(r17 の前の試し・メモリの上)で、問い K の組を作り直し、閉じた K と照らす。
