## 3. LLM に任せる範囲(不変原則 1 の、例外の線の、引き直し)

| 段 | LLM | 決定論のコード |
|---|---|---|
| 読む(新しく、広げる) | **行の役割・済んだか・どの設備の、どの結果か・今の測りか**を、選びの番号で、返す(自由な文は、返させない)。**判別に、近い**。ただし、返事は、票の 1 つ | 形の照らし・票から、段と重みを出す・保存 |
| 知識を作る | 「なぜ」の辺の、下書き(根拠の行の番号つき)= 改訂 1 と同じ | 根拠の行との照らし・語の正規化・出どころの印 |
| 予想する | **使わない** | 逆たどり・足し合わせ・下げる・順位・次の確かめ・出典 |
| 採点 | 今の判定器(L3 v2)= 今までと同じ | 集計 |

- 囲い = (ア) LLM の返事は、票の 1 つ (イ) 数にするのは、決定論 (ウ) 票は、全部、残る (エ) 予想は、決定論 (オ) 作った物は、「推論」の印つきで、今の B・D-KG と、混ぜない。

## 4. 作り(段 1 の試しの範囲)

### 4-1. 読み手と、票

| 読み手 | 中身 |
|---|---|
| LLM A | 今の既定(Bedrock・jp の Claude Opus 4.7) |
| LLM B | **別の系統**(§7 の U2 で、決める) |
| 型 v0・型 v2 | 今日 作った物。**直さない**。v2 の「迷う行」の札は、グレーの印 |
| 時刻の読み | timeread-v3(固定済み)。時刻が戻る所は、後知恵の度合いを、上げる側に |
| 人 | 利用者の答え(今 12 行 + 割れの大きい行を、1 回・約 10 問) |

- LLM は、事故 1 件を、1 回で読む。返すのは、行ごとの、選びの番号の表と、辺の下書き。
- 票から出す物 = 問いごとの割合と、票の数 → **3 段**(高・中・低。しきいは、数を見る前に、決める)。行ごとの「後知恵の度合い」。小数は、画面と報告に、出さない。

### 4-2. 知識の辺

- 型 A(原因 → 現象)・型 B(下げる)・型 C(調べた理由)。**原因が、確定しなかった事故**(様子見で、引き上げ)からも、低い段の辺として、採る。
- どの辺にも = 出どころ(事故 ID・行の番号・群)・読みの段・支える群の数・読み手の割れ。支える群が 1 つだけの辺だけで、候補を「高」に、しない。

### 4-3. 予想の計算(決定論・式は、数を見る前に、固定)

| 決め | 中身 |
|---|---|
| 足し方(主) | 同じ群から出た根拠は、1 つにまとめ、**別々の群の、弱い根拠が、重なるほど、上がる**形(上限つき)。掛け算で、0 に、しない |
| 足し方(照らし) | 単純な、票の数え(pla の形)。**同じ保存済みの読みから、両方を計算**し、式で、順位が、どれだけ変わるかを、並べる |
| 下げる | 正常の観測で、候補を、下げる。**床を置く**。同じ設備への下げは、1 事故で、いちばん強い 1 回だけ |
| ハブの歯止め | どの問いでも出やすい分(下地)を、引く・弱い根拠の、足せる数の上限・候補の数の上限 |
| 見せ方 | 「どの読みでも、支持が在る候補」→「特定の読みだけの、弱い候補」。段と、根拠の内訳(強 n・弱 m・下げた k)。低の段だけの時は、「当てに、できない」と書く |

### 4-4. 後知恵の扱い(評価の入力を、3 水準で)

| 水準 | 入力 | 言える事 |
|---|---|---|
| S0 | 初めの知らせだけ(**初めの知らせだけを見せた読み**から) | 後知恵は、入らない |
| S1 | 全部の読み手が、「結論より前」と読んだ行だけ | **「類例なしで、当たった」は、S0 と S1 の成績だけで、言う** |
| S2 | 全部の行を、重みつきで | 「漏れを含み得る、上の限り」として、並べる |

- 採点の側で、入力の行に、正解の語が、そのまま在った問いを、分けて数える(dkb・決定論)。漏れを、係数で、差し引く事は、しない。

## 8. 守る事(変わらない)

- 原文は、不変。作った物を、B・D-KG・暗黙知 KB に、書かない。「推論である」印と、出どころを、必ず付ける。
- LLM に送るのは、伏せた本文だけ。外部エージェントには、架空の例・仕様・集計だけ。
- 評価の群(開発用・最終)の隔離。最終の群の中身と正解は、dkb だけ。最終は、1 回。
- 線と定数は、数を見る前に、固定し、動かさない。
- 出力は、助言(最終の判断は、人)。
