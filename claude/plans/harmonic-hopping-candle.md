# 計画: 推論 KB — 事故の「なぜ」を溜めて、論理の積み重ねで原因の候補を探す(決364・2026-11-22・改訂 0)

(この計画ファイルの前の中身 = ai-hub の汎用版の計画(11-20)は、承認済みで、決363 の dec に記録が在る。今回の計画で置き換える)

## 1. Context(なぜ、これを行うか)

- 今までは、事故摘録の**記載の内容**を知識にし、過去の事例との類似で、原因を推し量ってきた。類例の原因を引き出す方式の天井は、約 79%(推定・決355 の調べ)で、**類似の事例が無い事故が、相当の割合で残る**。
- 利用者の指示(2026-11-22・決364): 各事故の記録の「なぜ」(原因から現象への論理・調べた理由・絞り込みと排除の理由)を、LLM で考えて、**確からしさつきで溜め**、論理の積み重ねで、原因を推定する仕組みを作る。事故摘録の記載に基づく物(B・D-KG)とは、**DB も API も分ける**。暗黙知 KB(tkb)とも、別の扱い。
- pla(独立の計画)と agy(調べと意見)の意見は、揃った(決364 追補 1・2)。向きは同じで、矛盾は無い。この計画は、その 2 つと、2026-10-14 の調べ(決243〜247)を、基にする。

## 3. 方針(推し)

### 3-1. LLM に任せる範囲(不変原則 1 の、例外の線)

| 段 | LLM | 決定論のコード |
|---|---|---|
| 知識を作る(オフライン) | **例外として、使う**: 記録を手がかりに、「なぜ」の下書きと、確からしさの区分(3 段階)を作る | 根拠の所との照らし・語の正規化・時刻の前後・向きの検査・矛盾の検出・集計 |
| 問い合わせ(オンライン) | **使わない(0 回)** | 逆たどり・排除・順位づけ・次の確かめの選び・出典の表示 |

- LLM の自己申告の確からしさは、**人が確かめる順を決める事にだけ**、使う。順位には、使わない。
- 作った物の全部に、印(推論である)・出どころ(事故の ID・根拠の所)・モデルと指示の版・確認の状態を、持たせる。**記録の事実(B・D-KG)と、混ぜない。**

### 3-2. 溜める知識の形

| 型 | 中身 | 役割 |
|---|---|---|
| A 機序の一段 | 原因の側の状態 → 次に起きる状態(必要な条件・当てはまる設備の範囲) | 逆にたどって、候補を**広げる** |
| B 排除 | この観測が正常なら、この候補は、成り立たない | 候補を**削る**(未確認の間は、弱い減点だけ。誤ると、本当の原因を消すため) |
| C 調べた理由 | この確かめは、候補 X と Y を、切り分ける | **次に調べる事**を、理由つきで示す |
| D 観測を採らない理由 | 対象や時刻が違う・測り方が妥当でない・理由の記載なし | 観測の重みを下げる(元の値は残す) |

- **個別の理由**(その事故 1 件の物)と、**一般の規則**(事故をまたいで使える物)は、別の識別子。1 件だけの事例からの規則は、配らない(独立の事故 2 件以上か、人の確認が要る)。
- 中間の状態は、自由な文でなく、**(設備の部位, 状態の種類)の対**に、正規化する(語彙の DB V3 の語 ID と版)。対応の無い語は、保留(語彙の追加は、人手の承認)。つながりの数に、上限(巨大なハブを作らない = 決242 の、探索の口の誤答の増えを、繰り返さない)。
- **後知恵の遮断**: 型 B・C・D は、**原因の欄と、原因が分かった後の行を、決定論で切り落とした本文**から、先に作る(`response_log` の時刻の順で切る)。型 A は、その後に、原因を見せて作る。

### 3-3. 問い合わせの時の作り(決定論)

1. 入力(現象・分かっている観測)を、語彙で照らす。
2. 型 A を逆にたどり、候補を挙げる(深さと、候補の数に、先に決めた上限。打ち切った時は、表示)。
3. 候補ごとに、型 B で、観測と照らす(整合・矛盾・不明。書かれていない事は、不明)。
4. 候補が複数残れば、型 C から、**候補の間で、答えが分かれる確かめ**を選び、「結果がどちらなら、どの候補が残るか」を添えて、返す。
5. 答え = 候補・たどった論理の鎖と、各段の出典・確からしさ・まだ確かめていない条件・次の確かめ。「推論による助言」と表示。当てはまる規則が無ければ、理由つきで、保留。

- 確からしさ: 各段は、3 段階の区分と、独立の事故の数の、2 軸。鎖は、**いちばん低い段を、上限**にする(掛け算を、正答の確率として、出さない)。多くの原因から起きる現象は、合流の数で、寄与を割る(どの故障でも起きる現象 1 つで、特定の原因が、上がらないように)。較正は、未使用の事故の群で(件数が足りなければ、「未較正」と表示)。

### 3-4. 評価(生成の前に、隔離する)

- 同じ事故・転載・改訂・双子を、群にして、作る側・較正・最終の評価に、分ける。どの辺にも、出どころの事故の集合を持たせ、評価の時は、その事故だけが支える辺を、決定論で隠す。
- 「類似なし」を、「収録が無い」「在るが、検索で拾えない」「判定できない」に、分けて数える。
- 比べる物 = 今の B・D-KG / 専門家が書いた規則(対照・小さく)/ 推論 KB だけ / 今の物 + 推論 KB。
- 物差し = (1) 類例なしの問いで、正解が、上位の決めた数に入った割合(保留も分母)(2) 別々の事故の論理が、つながって、候補に届いた問いの数 (3) 候補の数の中央の値 (4) **誤った排除の数(目標 0)** (5) 同じ問いでの、改善と悪化の数。
- **「説明の質」と、「原因を当てる効果」を、別々に報告する。**
- 2 つの場面で測る: (ア) 初めの知らせだけ (イ) 記録の、切り分けの経過の観測を、時刻の順に、1 つずつ明かした時(対話の代わり)。

## 9. 計画が外れる所

- **記録に、候補を分ける時点の観測が、乏しい**(10-14 と同じ)。→ 段 0 で、見切る。説明だけが増えて、当たらない時は、そう報告する。
- もっともらしい物理の誤り(安全側の論理の、向きの取り違えなど)が、多くの事故に、複製される。→ 件数だけで、確定に上げない。幹の規則と、排除の規則は、人の確認。
- 中間の状態の粒度が、合わない(つながらない / 何でもつながる)。→ 段 1 の物差し (2)(3) で、判じる。
- 人の確認の負担が、溢れる。→ 代表で確かめて、機械を直す。回ごとに、問いの数が減る事を、確かめる。
