## 2. 作り(新しい道具 `scripts/dcr/misread_check.py`・決定論・LLM なし)

1. **見込みの語を出す(`reading_fix.py scan` の数えを関数にして使う)**
   - 語ごとに、次を持つ。
     - 層: 取り違えやすい字の組 / 同じ長さで 1 字違い / 2 字違い / 長さが違う
     - 出る所(行・頁・枠)
     - よくある語(ほかの本に 3 か所以上出る語のうち、字の違いが最も少なく、最も多く出る語)
2. **代表を選ぶ**(決定論・語の多い順に、同じ数なら語の sha256 の順)
   - 取り違えやすい字の組は全部(7)。ほかは、同じ長さで 1 字違いから 4、2 字違いから 3、長さが違う語から 3。
   - 外す語(R26): 社名の確かめの回で問うた語と重なる語(2)と、直しの台帳の語(1)。
   - 見込みは約 16 語。
3. **確かめの画面(共通の部品・第 5 版・語ごとに 1 問)**
   - 問い:「前の説明書のこの行で、印の付いた片仮名の語は、正しく読めていますか。右の画像(原本)と見比べてください」。
   - 右の資料:
     - その行の画像。原本の PDF の頁から、上下 1 行を含めて大きく切り出す。
     - 読取の字。怪しい語に印を付ける。
   - 選び: 読取のとおり(誤りでない)/ よくある語「…」の読み誤り / 別の字の読み誤り(正しい字の欄が開く)/ 分からない。
   - 語の説明(R15): 読み誤り・OCR(機械が画像から字を読むこと)・よくある語(ほかの資料に多く出る語)。
   - 備考は問いごとに付ける。
   - 画像と回は git 外の `data/private/misread_check/`(700/600)に置き、利用者のブラウザにだけ出す。dcr は画像も語も見ない。
4. **答えを取り込む(`apply`)**
   - 「よくある語の読み誤り」と「別の字の読み誤り」の語を、直しの台帳(reading_fix の台帳)に足す。
   - `reading_fix.py apply` で、書き出しの fixed に入れる(前の版を写し、check_input を通す)。
   - 分からない・答えの無い問い・終えた印の無い時は止める。分からないの問いは、出し直す前に何が見えていたかを調べる(R27)。
5. **層ごとの誤読の割合を数える(数だけを rep に)**
   - 答えで、探し方の決まり(層・字の組・照らしの元)を直す。直した決まりで残りを数え直し、次の回が要るかを見立てる。
   - 次の回は、別の計画で諮る。
6. **selftest(合成のデータだけ)**: 層の分け・代表の選び(決定論・外す語)・画面の問いの数と選び・答えから台帳(止める場合を含む)。
