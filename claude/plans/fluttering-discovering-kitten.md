## 2. 全文の読みの指示文(case_whole_v1)の要点

- 役目: 事例報告の文章から「言及」を**原文の字のまま**抜き書きし、決めた種類に振り分けるだけ。判断・推測・要約・言い換えはしない。
- 種類(kgb の型と同じ 8 つ): きっかけ(event)・見た事(observation)・確かめた事(check)・分かった事(finding)・原因の候補(cause_candidate)・判断(judgment)・処置や対策(countermeasure)・機器(equipment)。
- 原因の候補と判断には、確からしさの**言い回しの字だけ**を写させる(例「と推定される」)。**確定・推定などの名は書かせない**(名は表で決める)。
- 処置は、応急・恒久・再発防止の 3 つに分ける。区画(表紙・まとめ・原因・経過・対策・図の説明・付記・その他)と時刻の行も写す。
- つながり 4 種(きっかけ → 結果・根拠 → 判断・候補 → 否定した確かめ・処置 → その後)は、**原文に明記がある物だけ**。
- 言及を取らなかった単位を並べさせる(取りこぼしの目印)。出力は JSON だけ。
- 送るのは、伏せの照らしに合格した単位の字に、社名の表を当てた字だけ。1 本 3 回(Bedrock の Sonnet 5・思考は無効)。逐語の照らし・3 回のうち 2 回の一致・種類とつながりの照らしは、決定論の道具。

## 3. 画像の書き写しの指示文(case_image_v1)の要点

- 1 回に画像 1 枚。画像の種類を 6 つ(写真・波形やグラフ・画面の写し・図・表の写し・その他)から選び、画像に見える字と、数と単位の組を、**見えるとおりに**書き写すだけ。解釈(何が悪いか・原因)は書かせない。
- 人の名前・はんこ・会社の名に見える字は、写さずに「[伏せる字]」と書かせる(送る前に確かめていても、二重の守り)。
- 送るのは、画面 B で「写っていない」と答え、切り抜きの指紋が合う 28 枚だけ。1 枚 3 回。3 回の一致は決定論。

## 4. 言い回しの表 第 1 版(case_stance_table_v1)

- 決め方(決定論): AI が写した言い回しを字のそろえ(全角半角・空白)をしてから、表の語が含まれるかを照らす。当たる語が複数なら**いちばん長い語**の確からしさ、同じ長さなら「否定 > 調査中 > 意見 > 推定 > 確定」の順。当たらなければ「表に無い」の印を付け、確からしさは空にする(代表をお尋ねして表に足す)。

| 確からしさ | 表の語(第 1 版) |
|---|---|
| 否定 | 異常なし・異常は無・異常はな・問題なし・問題は無・問題はな・否定・ではない・では無い・該当しない・正常であ・正常だっ・原因ではな・関係はな・関係は無 |
| 調査中 | 調査中・確認中・調査する・調査を進め・今後調査・原因は不明・不明である・特定でき・特定に至ら・解析中 |
| 意見 | と考える・と思う・ではないか・と見る・私見 |
| 推定 | 推定・と思われる・可能性・考えられる・疑われる・と見られる・おそれ・恐れ・らしい・ようだ・模様 |
| 確定 | 確認した・確認された・判明・認めた・認められた・特定した・であった・原因である・原因であった・によるもの・確定 |

- 合成の言い回しでの試し: 「が原因と推定される → 推定」「を確認した → 確定」「異常は無かった → 否定」「ではないかと考える → 意見」「原因ではないと考えられる → 否定」「とした → 表に無い」。
